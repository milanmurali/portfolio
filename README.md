# Milan Murali — Portfolio

Personal developer portfolio built with React, TypeScript, Vite, Tailwind CSS, React Router, and GSAP.

## Tech Stack

- React + TypeScript + Vite
- Tailwind CSS + Radix UI primitives
- React Router DOM
- GSAP + ScrollTrigger & Lenis
- React Hook Form + Zod

## Local Development

```bash
npm install
npm run dev
```

## Build

```bash
npm run lint
npm run build
```

## Contact Form (Optional)

Set `VITE_CONTACT_ENDPOINT` in a `.env` file to enable direct form submissions via an endpoint (e.g. Web3Forms or Formspree). Without it, the form prepares a `mailto:` draft.
